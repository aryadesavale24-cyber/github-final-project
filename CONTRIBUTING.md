# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Fork the Repository**: Fork this repository to your own GitHub account.
2. **Clone the Fork**: Clone the repository to your local system:
   ```bash
   git clone https://github.com/aryadesavale24-cyber/github-final-project.git
   ```
3. **Create a New Branch**:
   ```bash
   git checkout -b feature/improvement-name
   ```
4. **Make Changes**: Implement your improvements, bug fixes, or documentation updates.
5. **Test Your Changes**: Verify that the script executes cleanly:
   ```bash
   bash simple-interest.sh
   ```
6. **Commit and Push**:
   ```bash
   git add .
   git commit -m "Description of changes"
   git push origin feature/improvement-name
   ```
7. **Open a Pull Request**: Submit a pull request to the `main` branch with an explanation of your modifications.

Thank you for contributing to our project!
