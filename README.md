# Simple Interest Calculator

A simple calculator application that computes simple interest based on user input for principal, annual rate of interest, and time period in years.

## Description
This project contains a Bash script (`simple-interest.sh`) designed to help users quickly calculate simple interest for financial or educational purposes.

## Input Fields
- **Principal ($p$)**: The initial amount of money borrowed or invested.
- **Rate of Interest ($r$)**: The annual interest rate percentage.
- **Time Period ($t$)**: The duration the money is borrowed or invested for (in years).
